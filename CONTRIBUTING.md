# Maintenance policy

This project is maintained by Modern X Webs. The source is published for
transparency, inspection, reproducible checks and permitted reuse.

We are not accepting external code contributions or unsolicited pull requests.
The maintainer may close them without review. An open source license grants
reuse rights; it does not promise contribution review or support.

For a bug report, email dev@modernxwebs.com with the affected page, browser,
steps to reproduce and a minimal synthetic example if possible. Do not send
personal photographs, confidential documents, extracted private metadata,
credentials or other sensitive material.

For a security concern, follow [SECURITY.md](SECURITY.md) and report it privately.
Do not publish exploit details or sensitive examples in a public issue.
